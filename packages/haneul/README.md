# 하늘 (空)

Haru에서 쓰는 웹 프레임워크예요. Flask처럼 앱을 만들고 경로마다 처리기를 붙이면 돼요. `haru`에 들어 있어서 따로 설치하지 않아도 돼요. Haru 전용이라 Hana에서는 돌지 않아요.

```hari
[하늘]에서 <앱>을 가져오자

'앱'을 <앱>()으로 정하자

<인사>를 만들자 ('요청'):
    틀"<h1>안녕, {'요청'의 <인자>("이름")}!</h1>"을 돌려주자

'앱'의 <GET>("/안녕/<이름>", <인사>)를 실행하자
'앱'의 <실행>(5000)을 실행하자
```

```kanade
【空】から〈アプリ〉を持ってこよう

『アプリ』を〈アプリ〉()にしよう

〈挨拶〉を作ろう(『リクエスト』):
    枠「<h1>こんにちは、{『リクエスト』の〈引数〉(「名前」)}さん！</h1>」を返そう

『アプリ』の〈GET〉(「/こんにちは/<名前>」, 〈挨拶〉)を実行しよう
『アプリ』の〈実行〉(5000)を実行しよう
```

`haru run 앱.hr`로 띄우고 http://127.0.0.1:5000/안녕/하루 를 열어 보세요. 할 일 목록 예제는 [`example/`](example)에 있어요.

## 처리기가 돌려주는 것

| 돌려준 값 | 응답 |
| --- | --- |
| 글 | HTML (`text/html; charset=utf-8`), 상태 200 |
| 사전, 목록 | JSON (`application/json`), 상태 200 |
| `비어있음` | 본문 없이 204 |
| `<응답>`, `<JSON응답>`, `<리다이렉트>`, `<파일보내기>`로 만든 응답 | 그대로 |

처리기는 `('요청')`처럼 요청을 받아도 되고, 필요 없으면 `()`로 만들어도 돼요.

## 경로 규칙

| 규칙 | 맞는 경로 | `<인자>`로 받는 값 |
| --- | --- | --- |
| `/글/<제목>` | `/글/첫글` | 글 `"첫글"` (`/`는 못 넣어요) |
| `/글/<int:번호>` | `/글/42` | 숫자 `42` (0 이상의 정수) |
| `/값/<float:x>` | `/값/1.5` | 숫자 `1.5` |
| `/파일/<path:경로>` | `/파일/a/b.txt` | 글 `"a/b.txt"` (`/`까지 받아요) |

변환 이름은 `정수`, `숫자`, `경로`, `글`로 써도 돼요. 규칙이 `/`로 끝나면(`/목록/`) `/목록`은 `/목록/`으로 보내요(308). 경로는 맞는데 메서드가 다르면 405와 `Allow` 헤더로 답하고, `OPTIONS`와 `HEAD`(GET 규칙으로)는 저절로 답해요. 여러 규칙이 맞으면 고정된 부분이 많은 쪽이 이겨요.

## 함수

| 하리 | 카나데 | 하는 일 |
| --- | --- | --- |
| `<앱>()` | `〈アプリ〉()` | 앱을 만들어요 |
| `<응답>(본문?, 상태?, 헤더?)` | `〈応答〉` | 응답을 만들어요. 본문은 글(HTML), 사전·목록(JSON), `비어있음` |
| `<JSON응답>(값, 상태?)` | `〈JSON応答〉` | JSON 응답 |
| `<리다이렉트>(주소, 상태?)` | `〈リダイレクト〉` | 다른 주소로 보내요 (기본 302) |
| `<중단>(상태, 메시지?)` | `〈中断〉` | 처리를 멈추고 그 상태의 오류로 답해요 (`abort`) |
| `<템플릿>(파일, 값들?)` | `〈テンプレート〉` | 템플릿 폴더의 파일을 그려요 |
| `<템플릿문자열>(글, 값들?)` | `〈テンプレート文字列〉` | 글을 템플릿으로 그려요 |
| `<파일보내기>(경로, 형식?)` | `〈ファイル送信〉` | 파일을 응답으로 (없으면 404) |
| `<이스케이프>(글)` | `〈エスケープ〉` | HTML에 넣을 수 있게 `<`, `&` 등을 바꿔요 |

## 앱 (`'앱'의 <…>`)

| 하리 | 카나데 | 하는 일 |
| --- | --- | --- |
| `<GET>` `<POST>` `<PUT>` `<PATCH>` `<DELETE>`(규칙, 처리기) | 같음 | 경로에 처리기를 붙여요 |
| `<라우트>(메서드들, 규칙, 처리기)` | `〈ルート〉` | 메서드 여러 개 (`["GET", "POST"]`) |
| `<요청전>(처리기)` | `〈リクエスト前〉` | 모든 요청 전에 `처리기(요청)`. `비어있음`이 아닌 값을 돌려주면 그게 응답이 돼요 |
| `<요청후>(처리기)` | `〈リクエスト後〉` | 응답 뒤에 `처리기(요청, 응답)`. 응답을 돌려주면 그걸로 바꿔요 |
| `<오류처리>(상태, 처리기)` | `〈エラー処理〉` | `<중단>`, 없는 주소(404), 메서드(405), 프로그램 오류(500) 때 `처리기(요청, 메시지)` |
| `<정적폴더>(주소, 폴더)` | `〈静的フォルダ〉` | 폴더의 파일을 그대로 내줘요 (기본: `/static` → `static`) |
| `<템플릿폴더>(폴더)` | `〈テンプレートフォルダ〉` | 템플릿을 찾는 폴더 (기본 `templates`) |
| `<비밀키>(글)` | `〈秘密鍵〉` | 세션 쿠키에 서명하는 키 |
| `<디버그>(참)` | `〈デバッグ〉` | 500 페이지에 오류 문구를 보여줘요 |
| `<기록>(거짓)` | `〈ログ〉` | 요청 기록(표준 오류)을 끄거나 켜요 |
| `<실행>(포트?, 주소?)` | `〈実行〉` | 요청을 받아요 (기본 `127.0.0.1:5000`). `<멈추기>`까지 돌아와요 |
| `<멈추기>()` | `〈停止〉` | `<실행>`을 끝내요 |
| `<시험요청>(메서드, 경로, 본문?, 헤더?)` | `〈テストリクエスト〉` | 네트워크 없이 요청을 보내 응답을 받아요 (시험용). 사전·목록 본문은 JSON으로 가고, 앱이 준 쿠키는 다음 시험 요청에 따라가요 |

폴더(템플릿, 정적 파일)는 `haru run`을 실행한 폴더에서 찾아요.

## 요청 (`'요청'의 <…>`)

| 하리 | 카나데 | 돌려주는 것 |
| --- | --- | --- |
| `<메서드>()`, `<경로>()`, `<쿼리문자열>()` | `〈メソッド〉` `〈パス〉` `〈クエリ文字列〉` | `"GET"`, 풀린 경로, `?` 뒤의 글 |
| `<인자>(이름)`, `<인자들>()` | `〈引数〉` `〈引数一覧〉` | 경로 규칙의 값 |
| `<쿼리>(이름, 기본값?)`, `<쿼리들>()`, `<쿼리목록>(이름)` | `〈クエリ〉` `〈クエリ一覧〉` `〈クエリリスト〉` | `?이름=값` |
| `<폼>(이름, 기본값?)`, `<폼들>()`, `<폼목록>(이름)` | `〈フォーム〉` `〈フォーム一覧〉` `〈フォームリスト〉` | `application/x-www-form-urlencoded` 본문 |
| `<JSON>()` | `〈JSON〉` | JSON 본문 (비었으면 `비어있음`, 틀리면 400) |
| `<본문>()` | `〈本文〉` | 본문 글 |
| `<헤더>(이름)`, `<헤더들>()` | `〈ヘッダー〉` `〈ヘッダー一覧〉` | 헤더 (이름의 대소문자는 가리지 않아요) |
| `<쿠키>(이름)`, `<쿠키들>()` | `〈クッキー〉` `〈クッキー一覧〉` | 쿠키 |
| `<주소>()` | `〈アドレス〉` | 보낸 쪽 IP |
| `<넣기>(키, 값)`, `<꺼내기>(키, 기본값?)` | `〈入れる〉` `〈取り出す〉` | 이 요청 동안만 쓰는 저장소 (`g`) |
| `<세션값>(키, 기본값?)`, `<세션설정>(키, 값)`, `<세션삭제>(키)`, `<세션비우기>()` | `〈セッション値〉` `〈セッション設定〉` `〈セッション削除〉` `〈セッション消去〉` | 세션 |
| `<세션>()` | `〈セッション〉` | 세션 사전 그 자체 |

없는 값은 `비어있음`이에요. 세션은 서명한 쿠키(`session`)에 JSON으로 들어가서, `<비밀키>`가 있어야 쓸 수 있어요. 바뀐 요청에서만 쿠키를 다시 보내요.

## 응답 (`'응답'의 <…>`)

| 하리 | 카나데 | 하는 일 |
| --- | --- | --- |
| `<상태>()`, `<본문>()`, `<JSON>()`, `<헤더>(이름)`, `<헤더들>()` | `〈状態〉` `〈本文〉` `〈JSON〉` `〈ヘッダー〉` `〈ヘッダー一覧〉` | 읽기 |
| `<상태설정>(상태)`, `<헤더설정>(이름, 값)` | `〈状態設定〉` `〈ヘッダー設定〉` | 바꾸고 그 응답을 돌려줘요 |
| `<쿠키설정>(이름, 값, 옵션?)`, `<쿠키삭제>(이름)` | `〈クッキー設定〉` `〈クッキー削除〉` | 옵션: `max_age`, `expires`, `path`, `domain`, `secure`, `httponly`, `samesite` |

## 템플릿

Jinja와 거의 같아요. 출력은 언제나 HTML 이스케이프돼요(`|safe`로 끌 수 있어요).

```jinja
{% extends "base.html" %}
{% block body %}
<ul>
  {% for 할일 in 할일들 %}
  <li>{{ loop.index }}. {{ 할일.제목 }}{% if 할일.끝 %} ✔{% endif %}</li>
  {% else %}
  <li>할 일이 없어요</li>
  {% endfor %}
</ul>
{% endblock %}
```

- 태그: `{{ 식 }}`, `{% if %}`/`elif`/`else`, `{% for a in 목록 %}`/`else` (`loop.index`, `index0`, `first`, `last`, `length`, `revindex`), `{% for 키, 값 in 사전.items() %}`, `{% set 이름 = 식 %}`, `{% block %}`/`{% extends %}`/`{{ super() }}`, `{% include %}`, `{# 설명 #}`, `{% raw %}`.
- 식: `+ - * / // %`, `~`(이어 붙이기), `== != < > <= >=`, `and or not`, `in`, `a if 조건 else b`, `사전.키`, `사전["키"]`, `목록[1]`, `range(끝)`.
- 검사: `is defined`, `undefined`, `none`, `number`, `string`, `mapping`, `sequence`, `even`, `odd`, `divisibleby(n)`.
- 필터: `safe`, `escape`/`e`, `upper`, `lower`, `title`, `capitalize`, `trim`, `length`/`count`, `default`/`d`, `join`, `first`, `last`, `reverse`, `sort`, `unique`, `list`, `sum`, `min`, `max`, `abs`, `round`, `int`, `float`, `string`, `replace`, `truncate`, `wordcount`, `center`, `indent`, `items`, `tojson`, `urlencode`, `striptags`, `nl2br`.

하리에 맞춘 것들:

- 색인은 1부터예요. `목록[1]`이 첫째, `목록[-1]`이 마지막이에요. `range(3)`은 1, 2, 3이에요(끝 포함).
- `참`/`거짓`/`비어있음`(`真`/`偽`/`空っぽ`)을 `true`/`false`/`none`처럼 쓸 수 있어요. 값은 프로그램이 출력하듯 나오고, `비어있음`은 아무것도 나오지 않아요.
- 블록 태그는 뒤의 줄바꿈과 앞의 들여쓰기를 가져가요(Jinja의 `trim_blocks`, `lstrip_blocks`). `{%-`, `-%}`는 그쪽 공백을 모두 지워요.
- 사전은 순서가 없어서 키 순서로 돌아요.

## 알아 둘 것

- 처리기는 프로그램의 스레드에서 하나씩 돌아요. 연결은 다른 스레드들이 읽어서 넘겨줘요(`http_server` 패키지와 같은 방식).
- `multipart/form-data`(파일 올리기)와 HTTPS는 아직 없어요. HTTPS가 필요하면 앞에 리버스 프록시를 두세요.
- 본문은 16MB까지 받아요.
